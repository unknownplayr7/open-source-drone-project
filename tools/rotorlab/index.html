Read the fine print (the useful kind)

This is a first-pass calculator, not a flight approval. Motor thrust figures depend on the exact motor, propeller, voltage, and test conditions. Static thrust is not the same as safe controllability, and the endurance estimate excludes changing throttle, voltage sag, wind, temperature, and battery aging.

For a real build, validate motor/propeller combinations against manufacturer test data, check ESC and battery current ratings, inspect the frame and fasteners, and follow local airspace rules. Test with propellers removed whenever practical during electronics setup.

RotorLab is an educational, client-side tool. Inputs stay in this page; nothing is uploaded. Estimates are intentionally simple and should be treated as rough planning numbers.
